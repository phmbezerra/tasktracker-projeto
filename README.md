# TaskTracker

Aplicação de linha de comando desenvolvida em Python para cadastro e visualização de tarefas.

## Funcionalidades

- Cadastrar novas tarefas
- Validar título obrigatório
- Validar prioridade
- Visualizar tarefas cadastradas
- Exibir status da tarefa

## Dados de uma tarefa

Cada tarefa possui:

- Título
- Descrição
- Prioridade
- Data limite
- Status
